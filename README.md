# Codex Arcanum — D&D 5e Character Creator

A full PHB-style D&D 5e character creation wizard built with React + Vite.

## Features

- Both **2014** and **2024** 5e edition support (toggle at any time)
- 20+ species/races with full trait listings and sub-options
- All 12 base classes, full level 1–20 feature tables, 3+ subclasses each
- 13+ backgrounds per edition with traits, ideals, bonds, and flaws
- 100+ spells filterable by level, school, and class
- Point Buy, Standard Array, or Manual ability score entry
- Live character sheet sidebar preview
- PHB aesthetic: parchment, Cinzel/EB Garamond fonts, dark red + gold

## Dev

```bash
npm install
npm run dev
```

## Adding Artwork

Place images in `public/art/` and update `src/data/art.js`. See `ARTWORK.md` for the full list.
